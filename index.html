MNV Sheets

MNV Sheets is a Google Sheets add-on for steel pipe and hollow section production planning. It runs inside Google Sheets and adds a menu under Extensions → MNV Sheets.

Features

  • Inventory check (CHECKTON) of a production plan against stock files (.xlsx) chosen from the user's computer, with optional Stock List and material reports.
  • Old-stock processing, production plan overview, size and product-code splitting.
  • Container allocation and optimization; highlighting differences between two columns.
  • Inventory configuration that can be exported/imported between the Excel, LibreOffice and Google Sheets editions.
  • Custom function USDRATE() (Vietcombank transfer rate).

How it works

All calculations run locally in the user's browser (WebAssembly). Spreadsheet data is read and written only in the spreadsheet the user is working on and is never sent to or stored on any server operated by the developer. The add-on is intended for internal use; features require an activation code issued by the developer.
