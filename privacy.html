MNV Sheets — Privacy Policy

Last updated: 7 November 2026

This policy describes how the Google Sheets add-on "MNV Sheets" (the "Add-on"), developed by Nguyen Van Manh ("we"), accesses, uses and protects data. Contact: vanmanhvcu@gmail.com.

1. Data the Add-on accesses

  • Spreadsheet content (scope spreadsheets): cell values, formulas, formatting, notes and row groups of the spreadsheet in which the user runs an Add-on command, so that the command can read the production plan and write its results (values, colors, notes and report sheets) back into that spreadsheet.
  • The user's email address (scope userinfo.email): used only to bind and check the activation code issued for that user.
  • Files the user selects: stock files (.xlsx) the user picks from their own computer in the Add-on sidebar. They are read only inside the user's browser.
  • External requests (scope script.external_request): the Add-on downloads its calculation engine (static files) from chinhdai.github.io, reads the activation revocation list from our Google Apps Script web app, and the optional USDRATE() function reads the public exchange-rate feed of Vietcombank. No spreadsheet data is included in these requests.
  • User interface (scope script.container.ui): to show the menu, sidebar and dialogs.

2. How data is used and processed

All calculations are performed locally in the user's browser. Spreadsheet data and selected files are not transmitted to, stored on, or shared with any server operated by us or any third party. The Add-on stores only its own settings (inventory configuration, code prefixes) and activation records in Google's PropertiesService of the user's account. For activation management, we keep a list of the email addresses and device identifiers we have issued activation codes to; it is used only to issue and revoke activation codes.

3. Sharing

We do not sell, rent, or share user data with third parties, and we do not use it for advertising.

4. Google user data

The Add-on's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Retention and deletion

Settings stored by the Add-on remain in the user's Google account until the user removes the Add-on or asks us to delete them. To request deletion of activation records, email us; we will delete them within 30 days. Users can revoke the Add-on's access at any time at myaccount.google.com/permissions.

6. Security

Data stays within Google's infrastructure and the user's browser; communication uses HTTPS.

7. Changes

We may update this policy; the date above shows the latest version.
